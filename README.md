# ИПФ — обучение сотрудников (М Булак, Исламское окно)

PWA на двух языках (RU / Кырг): тезисы урока + тест. Прогресс хранится в браузере (localStorage), логина нет.

## Как открыть локально
    cd /workspace/ipf-app/site && python3 -m http.server 8000
Открыть http://localhost:8000 . На телефоне: «Добавить на главный экран».

## Как добавить урок после тренинга
1. Заполнить `lessons/00N.json` (`title`, `goal`, `theses`, `quiz` — каждое текстовое поле `{"ru": "...", "ky": "..."}`; `correct` — индекс правильного ответа с 0).
2. В `lessons/index.json` поставить этому уроку `"ready": true`.
3. Поднять `VERSION` в начале `app.js` и `?v=` в `index.html`, чтобы телефоны получили обновление.

Урок засчитывается при результате теста ≥ 80%.
